## Core loop

Kill enemies → earn money → enter build mode → attach new parts to your tank → survive longer → earn more money.

## Controls

- **W / S** — forward / reverse (with acceleration and deceleration for weight)
- **A / D** — rotate left / right
- **B** — toggle build mode
- **1 / 2 / 3** — switch weapon to build

## Build mode

Pressing **B** pauses the game. You can then attach weapons to your tank — machine gun, cannon, or wall — limited only by how much money you've banked. There's no cap on the number of parts, so combinations snowball.

## Enemy waves

Enemies spawn around the tank on a timer:

| Time | Spawns |
|---|---|
| 0:00 – 1:00 | Zombies |
| 1:00 – 2:00 | Vampires |
| 2:00 – 3:00 | Egg monsters |
| 3:00+ | Multiple spawns, escalating |

Each enemy has its own move and attack — some long-range, some close-range.

## What I did

Programming the controller, build mode, and wave spawner, plus scene design.

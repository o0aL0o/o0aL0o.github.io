## Concept

A webcam-based arcade game. The webcam tracks a blue circular token (held or worn by the player). Green targets spawn every 3 seconds — when the blue token overlaps one, you score a point. Red rectangles act as traps — hit one and the run ends.

## How it works

1. Open the webcam
2. Display a scoreboard
3. Spawn a green circle at a random position every 3 seconds
4. Detect collision between the blue token and the target — if so, remove the target and add 1
5. Spawn three red rectangles at random positions
6. Detect collision with a red rectangle → freeze the webcam, print "Finish", and display the final score

## What I learned

- Webcam-based interaction is more demanding than mouse/keyboard — the threshold for "collision" has to be forgiving
- Spawn rate is the main difficulty knob, not enemy count
- A simple game loop (spawn → detect → score → repeat) is the cleanest way to scaffold a CV-driven game

## Concept

Most Cantonese-learning apps are dull. We wanted one that feels like a small game. Earn coins by completing vocabulary and quiz tasks, then spend them in a shop to customize an AI companion — hats, clothes, face, color.

A profile system layers on top: friends, progress, and coin balance all in one place.

![Onboarding screens](/images/canton1.png)
![Lesson flow](/images/canton2.png)

## Features

- Vocabulary + quiz core loop
- AI speak-aloud for pronunciation
- AI Q&A for freeform questions
- Coin shop with AI companion customization
- Friend list and progress dashboard

## What I did

Brainstormed the feature set, designed the UI, built the Figma prototype, and ran user tests.

## Loop

Shoot monsters → earn XP → level up → pick one of three upgrade cards → reach the level exit → next level ramps up the difficulty.

## Controls

- **WASD** — move
- **Space** — shoot
- **F** — interact

## Upgrade cards

1. **+HP** — extra heart
2. **+Damage** — heavier hit
3. **+Speed** — move faster
4. **Lightning ball** — new attack; unlocks a second one at level 3

## What I did

Programming the core gameplay, contributing to game ideas, designing scenes, and drawing the sprites.
